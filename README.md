# Knowledge Hub Library – Library Usage Analytics

## Project Overview
This Power BI-based data analytics project focuses on analyzing library usage, book borrowing patterns, member activity, return behaviour, and overdue transactions to support data-driven library management decisions.

## Project Objectives
- Analyze overall library usage and borrowing activity.
- Understand member borrowing patterns.
- Monitor book return and overdue transactions.
- Identify key library performance indicators.
- Present insights through an interactive Power BI dashboard.

## Tools Used
- Microsoft Power BI
- Python
- Pandas
- NumPy
- Data Cleaning
- Data Visualization
- KPI Reporting

## Dataset Information
- Original Dataset: 1,212 rows
- Final Cleaned Dataset: 1,200 rows
- Duplicate Records Removed: 12

## Data Cleaning
- Identified missing values.
- Checked dataset quality.
- Removed duplicate records.
- Cleaned and prepared data using Python.
- Created the final cleaned dataset containing 1,200 records.

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Transactions | 1,200 |
| Returned Transactions | 906 |
| Not Returned Transactions | 294 |
| Return Rate | 75.50% |
| Overdue Transactions | 293 |
| Average Loan Duration | 20.29 Days |
